# AIS+ Privacy Policy

**Effective date:** 27 August 2026

AIS+ is a local browser extension for `is.stuba.sk`.

## Data collection

AIS+ does not collect, transmit, sell or share personal, academic or browsing data. There is no
analytics service, advertising SDK, remote API or extension-operated server.

## Local storage

The extension uses the browser `storage` permission only for these preferences:

- whether AIS+ is enabled;
- light, dark or system theme;
- compact mode;
- collapsed sidebar state;
- English, Slovak or Czech panel language.

These preferences stay in the browser profile and can be removed by uninstalling the extension or
clearing its storage.

## Website access

Access is limited to `https://is.stuba.sk/*`. AIS+ reads the page structure to restyle it and to find
the real navigation links available to the signed-in user. It does not read or modify other websites.
