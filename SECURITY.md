# Security Policy

## Supported version

Security fixes are applied to the latest release of UIS+.

## Reporting a vulnerability

Please avoid publishing account data, active sessions or student information in an issue. Send a
private message to [Yehor Halytskyi on LinkedIn](https://www.linkedin.com/in/yehor-halytskyi-392b92427/)
with a concise reproduction and the affected version. You can expect an acknowledgement within seven days.

## Extension boundaries

UIS+ has no backend. Its host access is restricted to `https://is.stuba.sk/*`, and the only extension
permission is local settings storage.
